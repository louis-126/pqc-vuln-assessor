Scan a post-quantum crypto implementation

Point it at a library's source — a GitHub repo or a local folder. The tool detects which library it is, then runs an evidence-grounded hunt for PQC vulnerability classes.

ⓘ New here? How a scan works
  1. Point at the source. Paste a GitHub URL, or a local folder path (drag one in).
  2. Detect the library. Click Detect library — it reads function names to identify it (e.g. Botan, wolfSSL).
  3. Run & read. The scan streams progress, then opens a report with CWE/CVSS findings.

Defaults are safe: local Ollama backend, agent-review mode.
