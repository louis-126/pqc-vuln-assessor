ⓘ What goes in a library file?

A library file is TOML with up to three keys:

KeyRequiredWhat it does
langyes Source language — picks which files are searched. One of {{ langs|join(', ') }}.
entry_pointsrecommended The crypto functions the investigator starts from (decaps / encaps / keygen / sign / verify). Prefer unique names — a generic verify can anchor the wrong file. Omit and the scan runs discovery-only.
pki_entry_pointsoptional Provider-layer anchors (cert-path / OCSP-CRL / keystore). Only used when a scan runs with PQC_DISCOVERY_PASSES=pki.

Saving validates the file the same way the scanner loads it — a bad lang or a non-list of strings is rejected, so you can't break a scan from here.
